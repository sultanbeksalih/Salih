Шыққан index.html файлын кез келген мәтіндік редактормен (мысалы, Блокнот, VS Code немесе NotePad++) ашыңыз. Ішіндегі таза мәтіндік HTML кодын көшіріп (copy), осы жерге қайта жіберіңіз. Егер веб-сайт интерфейсінің немесе белгілі бір компоненттің (мысалы, онбординг, AI чат интерфейсі т.б.) дайын HTML/CSS кодын жасап беру керек болса, қандай бет керек екенін сипаттап жазсаңыз, жаңадан жазып бере аламын. бәрін Бұл файл — ZIP архивінің екілік (binary) форматындағы жиынтығы.
